
# Week 2 - Provider-Agnostic LLM Client

## Aim
To build a common LLM client interface that supports both a hosted API and a locally running Ollama model.

## Learning Objectives
- Understand provider abstraction.
- Implement a common interface using Python classes.
- Integrate Google Gemini API.
- Integrate Ollama with Llama 3.2.
- Switch between different LLM providers.
- Perform basic unit testing.

## Tools & Technologies
- Python
- Google Gemini API
- Ollama
- Llama 3.2
- Requests
- Python-dotenv
- Pytest

## Project Files
- `llm_client.py`
- `main.py`
- `test_client.py`
- `requirements.txt`
- `.env`

## Outcome
Developed a reusable LLM client that allows users to interact with different LLM providers through a common interface.
