
# Week 3 - LLM Monitoring with MongoDB

## Aim
To extend the provider-agnostic LLM client by monitoring token usage, response latency, and estimated API cost, and storing request details in MongoDB.

## Learning Objectives
- Capture input and output token usage.
- Measure response latency.
- Estimate API usage cost.
- Store successful and failed request details in MongoDB.
- Implement request timeouts.
- Add automatic retries for temporary failures.
- Retrieve stored usage records.

## Tools & Technologies
- Python
- Google Gemini API
- MongoDB Atlas
- PyMongo
- Requests
- Google GenAI SDK

## Project Files
- `main.py`
- `llm_client.py`
- `usage_logger.py`
- `test_client.py`
- `requirements.txt`
- `.env`

## Outcome
Developed an LLM monitoring application that records token usage, latency, estimated cost, and request status in MongoDB.
