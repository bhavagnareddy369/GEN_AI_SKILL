
# Week 4 - Comparison of BPE, WordPiece and SentencePiece Tokenizers

## Aim
To implement and compare BPE, WordPiece, and SentencePiece tokenization approaches using English, Telugu, and Hindi text.

## Learning Objectives
- Understand tokenization and token IDs.
- Explore word-level and subword-level tokenization.
- Understand Byte Pair Encoding (BPE).
- Understand WordPiece tokenization.
- Understand SentencePiece tokenization.
- Compare token pieces and token counts across languages.

## Models Used
- GPT-2 - BPE
- Multilingual BERT - WordPiece
- XLM-RoBERTa - SentencePiece

## Tools & Technologies
- Python
- Google Colab
- Hugging Face Transformers
- SentencePiece

## Outcome
Compared how different pretrained tokenizers split English, Telugu, and Hindi text and analysed the differences in token counts.
