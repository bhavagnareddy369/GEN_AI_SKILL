
# Week 1 - First LLM API Call

## Aim
To set up the development environment and make the first API call to a Large Language Model using the Google Gemini API.

## Learning Objectives
- Understand how LLM APIs work.
- Generate and securely configure an API key.
- Install the Google GenAI Python SDK.
- Initialize the Gemini client.
- Send prompts and receive AI-generated responses.
- Experiment with different prompts.

## Tools & Technologies
- Python
- Google Colab
- Google Gemini API
- Google GenAI SDK

## Implementation
1. Generate a Gemini API key.
2. Configure the API key using Colab Secrets.
3. Install the required Python library.
4. Initialize the Gemini client.
5. Send prompts to the model.
6. Display and experiment with generated responses.

## Outcome
Successfully connected Python with the Gemini API and generated responses using different prompts.
