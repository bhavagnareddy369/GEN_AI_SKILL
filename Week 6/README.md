
# Week 6 - Golden Set and Baseline Evaluation

## Aim
To create a golden question set containing expected answers and sources, perform the first baseline evaluation using a local LLM, and establish release v0.1.

## Learning Objectives
- Create a golden question set.
- Define expected answers and reference sources.
- Evaluate LLM-generated answers using keywords.
- Identify matched and missing keywords.
- Calculate keyword coverage scores.
- Classify responses as PASS or REVIEW.
- Generate baseline evaluation results.

## Tools & Technologies
- Python
- Ollama
- Llama 3.2
- Google Colab
- Requests

## Project Files
- `main.py`
- `requirements.txt`
- `golden_set.json`
- `baseline_results.csv`

## Implementation
1. Prepare a set of 30 golden questions.
2. Define expected answers, keywords, and sources.
3. Run the questions against Llama 3.2.
4. Compare generated answers with expected keywords.
5. Calculate keyword coverage scores.
6. Classify results as PASS or REVIEW.
7. Export evaluation results to a CSV file.

## Release
**Baseline Release: v0.1**

## Outcome
Created a 30-question evaluation dataset, executed the first baseline evaluation using Llama 3.2, and generated a CSV report containing evaluation results.
